The experiment

Defensible methodology
Design

28 scenarios × 5 models × 9 repeats

The experiment covered four functions of money with seven scenarios per function: Store of Value, Unit of Account, Medium of Exchange, and Settlement.

Repeat grid

3 temperatures × 3 seeds

Nine scheduled repeats combined nominal temperature labels 0.0, 0.3, and 0.7 with seeds 42, 123, and 456. This produced 1,260 responses followed by 1,260 judge classifications.

Provider caveat

Not every API exposed every control

Grok, Nemotron, and GLM supported the full grid. GPT supported seeds but not temperature. Claude Fable supported neither, so those runs are described as nominal repeats. Identical prompts can still produce different API outputs because generation is not always perfectly deterministic.
